{% if include.bilingual %}Gallerian ohjeet{% endif %} Gallery controls

{% if include.bilingual %}
  • Vaihda kuvaa nuolipainikkeilla tai näppäimistön nuolilla. Puhelimella voit pyyhkäistä, kun kuvaa ei ole lähennetty.
  • Lähennä ja loitonna napsauttamalla kuvaa, vierittämällä hiiren rullaa tai nipistämällä. Siirrä lähennettyä kuvaa vetämällä.
  • Lähennä haluttuun alueeseen pitämällä Ctrl painettuna ja vetämällä rajaus.
  • Näppäimet + ja − lähentävät ja loitontavat; 0 palauttaa koko kuvan näkyviin.
  • Sulje kuvakatselu Esc-näppäimellä, sulkupainikkeesta tai napsauttamalla kuvan ja painikkeiden ulkopuolelle.
  • Jos lataus on sallittu, saat täysikokoisen kuvan kuvakatselun latauskuvakkeesta.
{% endif %}
  • Change photos with the arrow buttons or keyboard arrow keys. On a phone, swipe when the image is not zoomed.
  • Zoom by clicking the image, scrolling the mouse wheel, or pinching. Drag a zoomed image to pan.
  • Hold Ctrl and drag to select an area to zoom into.
  • Use + and − to zoom; 0 fits the whole image.
  • Close the viewer with Esc, the close button, or by clicking outside the image and controls.
  • If downloads are enabled, use the viewer's download icon for the full-resolution image.
